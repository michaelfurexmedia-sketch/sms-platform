# Product boundaries

Complete frontend prototype. Authentication, payments, number assignment, provider verification and delivery are simulations. No live messages or charges. All example names, businesses, phone numbers and transactions are fictional. State is local to one browser and shared across prototype roles, never a production authorization mechanism.

Empty registrations are separate from Explore demo workspace. State transitions, immutable receipt snapshots, scoped opt-outs and scheduling live in typed domain functions behind replaceable services. Recurring/future delivery advances only while this prototype is open.
