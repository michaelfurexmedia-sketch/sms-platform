# Design system — Phase 1 brief

Temporary product name: **SMS Platform**. No permanent brand assets.

Establish one original direction after validating existing work. Preserve useful typography/layout work where original; do not copy either reference website. Expressive editorial marketing, efficient customer workflows and an enterprise operations admin UI share accessible components and tokens.

Phase 1 deliverables:
- Primitive → semantic → component tokens for color, typography, space, borders and motion.
- Central branding configuration for name, wordmark, logo, favicon, colors, domain, company details, support email, social links, email branding and SEO.
- Semantic navigation, keyboard/focus states, readable contrast, reduced motion, responsive layouts and consistent data visualization.
- Shared component specifications covering buttons, forms, tables, dialogs and loading/empty/error/success states.
- CSS-first motion and existing icons; add animation dependencies only when justified.

Local DESIGN.md records an earlier visual direction and an obsolete temporary name. This is reusable candidate work, not an approved final identity or a newly verified accessibility review. No new palette, typography or layout has been selected in preparation.
